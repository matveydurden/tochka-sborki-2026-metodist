# Прототип интерфейса к вопросу 3

Приложение к [продуктовому брифу](BRIEF.md#3-как-устроен-основной-сценарий-решения-кейса).

**Статический схематический прототип.** Экраны иллюстрируют планируемый пользовательский путь. Кнопки не работают, данные демонстрационные, результаты генерации и проверки не получены.

## Экран 1. Запрос на программу

```text
МЕТОДИСТ                         Новая программа

Что нужно подготовить?
┌──────────────────────────────────────────────┐
│ Анализ данных на Python для сотрудников      │
│ банка, 72 часа, очно-заочно, четыре недели.   │
│ Итог — защита проекта.                       │
└──────────────────────────────────────────────┘

Референсы: [Добавить DOCX, PDF или текст]
Прикреплено: Прошлая программа.docx

Уточнение: какой входной уровень слушателей?
[Работают в Excel, Python не изучали          ]

                         [Предложить каркас →]
```

Если не хватает обязательных параметров, сервис сначала задаёт вопросы. Ошибка чтения файла отображается рядом с ним; текст запроса сохраняется.

## Экран 2. Согласование каркаса

```text
Анализ данных на Python          Каркас · версия 1

Тип: повышение квалификации
Аудитория: сотрудники банка, начальный Python
Цель и результаты обучения: [Просмотреть / изменить]

Модуль                    Часы
Основы Python               10
pandas                      20
SQL                         12
Визуализация                10
Основы статистики           12
Проект и аттестация           8
Итого                       72 / 72

[Раскрыть темы и виды работы]  [Календарный график]

Каркас ожидает вашего согласования.
[Изменить каркас]          [Согласовать и продолжить]
```

Числа иллюстрируют интерфейс. При редактировании часы пересчитываются; противоречия должны быть устранены до перехода к содержанию. Генерация материалов начинается после явного согласования методистом.

## Экран 3. Материалы и замечания

```text
Анализ данных на Python          Проверка комплекта

Программа                 Готов черновик
Тесты и задания            Готов черновик
Слайды модуля pandas       Готов черновик

Часы                      Расхождений нет
Разделы шаблона            Заполнены
Покрытие результатов      Требуется исправление
Источники                 Требуется проверка

Замечание 1
Результат РО-3: «Выполнять объединение таблиц»
раскрыт в теме, но имеет только одно оценочное средство.
[Открыть связь] [Подготовить второе задание]

Замечание 2
Источник не подтверждён. [Проверить / заменить]

                         [Повторить проверку]
```

Статусы приведены как пример. Неподтверждённый источник не получает отметку о достоверности. При сбое модельного API показывается ошибка и возможность повторить шаг с сохранением согласованного каркаса.

## Экран 4. Просмотр и выгрузка

```text
Анализ данных на Python          Комплект · версия 2

[Программа] [Компетенции] [Тесты] [Задания] [Слайды]

Запросить изменение:
[Усложнить задание по объединению таблиц      ]
[Показать затрагиваемые материалы] [Применить]

Проверка: [Открыть отчёт и оставшиеся замечания]

[Скачать DOCX] [Скачать PPTX] [Скачать JSON]

Черновик для проверки методистом и преподавателем.
Реквизиты утверждения и подписи не заполнены.
```

Изменённые и зависимые материалы проверяются повторно. Продукт не присваивает программе статус официально утверждённой; выгрузка сохраняет сведения о нерешённых замечаниях.
