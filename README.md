# Методист

Концепция ИИ-помощника методиста для продуктового хакатона **«Точка сборки»**, 13–31 октября 2026 года.

**Команда «Пхукетская»:**

- Матвей Мусиенко — капитан, [@matveydurden](https://github.com/matveydurden).
- Захар Толошный — участник, [@xzx-xzxx](https://github.com/xzx-xzxx).

## Задача

Кейс № 1 — **«ИИ-агент для создания образовательных программ»**. Кейсодатели — Академия цифрового развития и GigaCowork; инфраструктура — Cloud.ru.

Методист описывает курс и прикладывает референсы. Сервис уточняет требования, предлагает каркас программы и после согласования готовит связанные учебные материалы. Проверяет распределение часов, покрытие результатов обучения, полноту разделов и источники. Итоговый комплект проверяет и утверждает человек.

Планируется поддержка программ повышения квалификации, включая стажировки, и общеразвивающих программ по ИТ-направлениям, с выгрузкой DOCX, PDF, PPTX и JSON.

## Статус

**Продуктовая концепция. Разработка не начата.** В репозитории нет работающего сервиса, интеграции с Cloud.ru или результатов испытаний. Название «Методист» — рабочее. Все показатели в брифе являются целями для проверки.

- [Продуктовый бриф — пять вопросов чекпоинта](BRIEF.md).
- [Схематический прототип интерфейса — приложение к вопросу 3](PROTOTYPE.md).

Бриф подготовлен для продуктового чекпоинта 15–16 октября. На этом этапе оцениваются соответствие задаче кейса и продуктовая ценность, максимум 10 баллов.

**[Репозиторий публичный](https://github.com/matveydurden/tochka-sborki-2026-metodist)** и доступен экспертам без авторизации. Его ссылку можно указать в карточке решения на платформе. Финальный PDF будет добавлен после завершения правок презентации. Формат брифа для чекпоинта: PDF до 10 слайдов, онлайн-доска или документ до двух страниц с открытым доступом.
